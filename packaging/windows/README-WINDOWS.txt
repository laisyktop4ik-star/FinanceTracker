FINANCETRACKER 1.1.0 — WINDOWS x64
=================================

1. Распакуйте ZIP-архив в отдельную папку.
2. Запустите FinanceTracker.exe.
3. При желании создайте ярлык через контекстное меню Windows.

Устанавливать .NET отдельно не требуется: сборка self-contained.

Личные данные сохраняются в профиле пользователя Windows, отдельно от папки
с программой. Для обновления замените файлы приложения новой версией — база
данных сохранится.

Важно: Windows-сборка создана кросс-компиляцией на Linux. Основная проверенная
платформа релиза — Linux x64.
