FINANCETRACKER 1.1.0 — УСТАНОВКА НА LINUX x64
================================================

Поддерживаются современные 64-битные дистрибутивы Linux, включая Fedora,
Ubuntu, Debian, Linux Mint, openSUSE и Arch Linux.

Установка
---------
1. Распакуйте архив полностью.
2. Откройте терминал в распакованной папке.
3. Выполните:

   chmod +x install.sh
   ./install.sh

4. Откройте FinanceTracker из меню приложений.

Root/sudo и отдельная установка .NET не требуются.

Обновление
----------
Скачайте новый архив и снова запустите ./install.sh.
Личная база данных и настройки сохранятся.

Удаление
--------
Удалить приложение, сохранив личные данные:

   ./uninstall.sh

Удалить приложение вместе с личными данными:

   ./uninstall.sh --remove-data

Расположение данных
-------------------
~/.local/share/FinanceTracker/

FinanceTracker работает локально, без браузера и обязательного интернета.
